# Дизайн-система Brass & Blade

Токены лежат в `src/styles/global.css`, в блоке `@theme` Tailwind CSS v4. Каждый токен сразу
становится классом: `--color-surface` → `bg-surface`, `--container-page` → `max-w-page`.

## Цвета

| Токен         | Значение  | Назначение                                  | Контраст на `bg` |
| ------------- | --------- | ------------------------------------------- | ---------------- |
| `bg`          | `#0F0F0F` | фон страницы                                | —                |
| `surface`     | `#1A1A1A` | карточки и блоки                            | —                |
| `surface-2`   | `#242424` | поля ввода, hover карточек                  | —                |
| `line`        | `#2E2E2E` | границы и разделители (только декор)        | —                |
| `control`     | `#6B6560` | рамки полей и чипов (WCAG 1.4.11)           | ≈ 3.3:1          |
| `fg`          | `#F2EDE4` | основной текст, кремовый                    | ≈ 16:1           |
| `muted`       | `#A8A29A` | второстепенный текст                        | ≈ 7.6:1          |
| `accent`      | `#C8A165` | латунь: главная кнопка, надзаголовки, метки | ≈ 8:1            |
| `accent-soft` | `#DDB87A` | hover главной кнопки                        | —                |
| `error`       | `#E5625E` | ошибки формы                                | ≈ 5.7:1          |
| `pole`        | `#8B2E2E` | декор «барбер-пол», никогда не для текста   | —                |

Правила:

- Текст пишем только цветами `fg`, `muted`, `accent` или `error`. Все они проходят WCAG AA на `bg` и `surface`.
- Акцент расходуем экономно: на одном экране одна главная кнопка.
- Глубину задаёт смена фона `bg` → `surface` → `surface-2`, тени не используем.

## Типографика

| Роль               | Шрифт   | Класс                          | Размер          |
| ------------------ | ------- | ------------------------------ | --------------- |
| Заголовок hero     | Oswald  | `text-[clamp(3rem,10vw,5rem)]` | 48–80 px        |
| Заголовок секции   | Oswald  | `text-4xl md:text-5xl`         | 36 / 48 px      |
| Заголовок карточки | Oswald  | `text-2xl`                     | 24 px           |
| Лид                | Manrope | `text-lg`                      | 18 px           |
| Основной текст     | Manrope | `text-base`                    | 16 px           |
| Подписи, метки     | Manrope | `text-sm` / `text-xs`          | 14 / 12 px      |
| Надзаголовок       | Oswald  | утилита `eyebrow`              | 14 px, разрядка |

- Oswald (`font-display`) набирается только капслоком: заголовки, кнопки, надзаголовки.
- Manrope (`font-sans`) — шрифт по умолчанию для всего остального.
- Оба шрифта вариативные, с кириллицей, подключены через Fontsource.

## Сетка и отступы

- Контейнер: `mx-auto max-w-page px-4 md:px-6` (1200 px, поля 16 / 24 px).
- Отступы — шаги Tailwind, кратные 8 px: `2, 4, 6, 8, 12, 16…`.
- Секция: `py-20 md:py-28`, между заголовком и содержимым `mb-12 md:mb-16`.
- Брейкпоинты стандартные: `sm` 640, `md` 768, `lg` 1024, `xl` 1280.

## Форма и границы

- Углы прямые (`rounded-none`): стиль строгий, без «мыльных» скруглений.
- Границы толщиной 1 px: `border-line` у карточек, `border-accent/60` у второстепенной кнопки.

## Движение

- Смена цвета на hover: `transition-colors duration-200`.
- Появление блоков при прокрутке: около 600 мс, `ease-out`, сдвиг на 16 px (появится на этапе 4).
- Любое движение, включая плавную прокрутку к якорю, работает только при `prefers-reduced-motion: no-preference`.
- Фокус с клавиатуры виден на любом интерактивном элементе: обводка 2 px цветом `accent`
  с отступом 3 px. Задаётся глобально, отключать её нельзя.

## Компоненты

### Button — `src/components/ui/Button.astro`

Кнопка действия. С `href` рендерится ссылкой, без него — `<button>`.

| Свойство  | Тип                    | По умолчанию | Описание                                                                 |
| --------- | ---------------------- | ------------ | ------------------------------------------------------------------------ |
| `href`    | `string`               | —            | Есть — рендерится `<a>`, нет — `<button>`                                |
| `variant` | `'primary' \| 'ghost'` | `'primary'`  | Главное или второстепенное действие                                      |
| `size`    | `'md' \| 'sm'`         | `'md'`       | Боковые поля 28 или 16 px (`sm` — шапка и карточки); высота всегда 48 px |
| `type`    | `'button' \| 'submit'` | `'button'`   | Тип `<button>`                                                           |
| …         | атрибуты `<button>`    | —            | `class`, `disabled`, `aria-*`, `data-*`                                  |

| Вариант   | Когда                                 | Вид                                       |
| --------- | ------------------------------------- | ----------------------------------------- |
| `primary` | Главное действие экрана: «Записаться» | Латунная заливка, тёмный текст            |
| `ghost`   | Второстепенное: «Смотреть цены»       | Прозрачная, латунная рамка, светлый текст |

| Состояние | Вид                                                                              |
| --------- | -------------------------------------------------------------------------------- |
| Обычное   | См. варианты                                                                     |
| Hover     | `primary` светлеет до `accent-soft`, у `ghost` рамка и текст становятся `accent` |
| Фокус     | Глобальная латунная обводка                                                      |
| Disabled  | Прозрачность 50 %, курсор `not-allowed`                                          |
| Загрузка  | Не нужна: сайт не отправляет запросы                                             |

Через `class` не перебивайте свойства, которые кнопка задаёт сама (`display`, `padding`): какой
из двух конфликтующих классов победит, решает порядок в CSS, а не в разметке. Для полей есть
`size`, а чтобы скрыть кнопку, оберните её в элемент с `hidden`.

Доступность: высота не меньше 48 px, это удобная цель для пальца. Надпись — действие, начинается
с глагола. Ссылка нужна для перехода, `<button>` — для действия на месте.

| ✅ Так                        | ❌ Не так                          |
| ----------------------------- | ---------------------------------- |
| «Записаться», «Смотреть цены» | «Подробнее», «Нажмите здесь», «ОК» |
| Одна `primary` на экран       | Две латунные кнопки рядом          |

### Section — `src/components/ui/Section.astro`

Обёртка блока страницы: якорь, контейнер и заголовок (надзаголовок, `<h2>`, лид).

| Свойство  | Тип      | Описание                                           |
| --------- | -------- | -------------------------------------------------- |
| `id`      | `string` | Якорь секции; заголовок получает `id="{id}-title"` |
| `eyebrow` | `string` | Надзаголовок                                       |
| `title`   | `string` | Текст `<h2>`                                       |
| `lead`    | `string` | Необязательный лид под заголовком                  |
| `class`   | `string` | Дополнительные классы для `<section>`              |

Доступность: у `<section>` стоит `aria-labelledby`, он указывает на `<h2>`, поэтому скринридер
объявляет секцию по её заголовку. Отступ от липкой шапки задаёт `scroll-padding-top` у `html`
(а на телефоне ещё и `scroll-padding-bottom` под плавающую кнопку): при переходе по якорю и при
движении фокуса элемент не уходит под шапку (WCAG 2.4.11).

### Badge — `src/components/ui/Badge.astro`

Метка: уровень мастера, услуга в отзыве, статус. Не интерактивна и не используется как кнопка.

### Утилита `eyebrow`

Надзаголовок над `<h2>` и в hero: Oswald 14 px, капслок, разрядка 0.3em, цвет `accent`.

### Field — `src/components/ui/Field.astro`

Подпись, поле ввода в slot и место для ошибки. Свойства: `label`, `for` (id поля),
`note` (приписка к подписи, например «необязательно»), `class`. Полю в slot нужен
`aria-describedby="{for}-error"`. Скрипт формы пишет ошибку в `{for}-error` и ставит полю
`aria-invalid`. Само поле оформляется утилитой `field-control`: поверхность `surface-2`,
рамка `control`, при ошибке — `error`.

### Утилита `chip`

Чип выбора: `<label class="chip">` со скрытым `sr-only` радио внутри. Обычный — рамка `control`, hover —
рамка `accent`, выбран — латунная заливка, фокус с клавиатуры — латунная обводка, недоступен
(`disabled`) — приглушённый зачёркнутый текст. Используется для мастера, времени и кнопок лайтбокса.

### Появление при прокрутке

Атрибут `data-reveal`: блок плавно проявляется и поднимается на 16 px, когда попадает в экран.
`Section` ставит его на заголовок и содержимое сам. Без JS и при `prefers-reduced-motion` блоки
видны сразу.

## Не выделяем

- `Card` в отдельный компонент не выделяем: карточки мастеров, отзывов и преимуществ слишком
  разные. Общие у них только классы `border border-line bg-surface`.
