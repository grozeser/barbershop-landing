`astro preview` с e2e-тестами в CI, смоук-тест прода — тот же набор e2e против живого адреса.

## Когда откатывать

- Смоук-тест против живого сайта падает.
- Страница не открывается, пустая или в консоли есть ошибки.
- Форма записи не доходит до экрана «Вы записаны».
- Lighthouse Performance или Accessibility ниже 90.

## Как откатить

1. `git revert <коммит>` и `git push` — CI соберёт и выложит предыдущее состояние (2–3 минуты).
2. Если нужно быстрее: в GitHub Actions перезапустить последний успешный запуск `Deploy to GitHub Pages`
   для прошлого коммита — он заново выложит его сборку.
3. После отката повторить смоук-тест против живого сайта.
